## Як запустити програму

Для виконання лабораторних робіт необхідно встановити Ruby.

**Перевірка версії Ruby:**

```bash
ruby --version
```

**Приклад запуску лабораторної роботи:**

```bash
cd lab01
ruby main.rb
```

Якщо конкретна робота має інший спосіб запуску, зазначте це в її директорії.
